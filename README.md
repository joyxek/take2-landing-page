# Take2 Landing Page

Next.js site for take2.social.

## Edit content
- Page text and links: `app/page.tsx`
- Styles and colors: `app/globals.css`
- Images: `public/assets/` (event photos are in `public/assets/photos/`)

## Run locally
```
npm install
npm run dev
```
Then open http://localhost:3000

## Deploy
Push to the `main` branch of the GitHub repo connected to the `take2-landing-page` Vercel project. Vercel builds and deploys it automatically.
